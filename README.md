# Campus Complaint Management System

## About the Project
The Campus Complaint Management System is a web application developed using Java and Spring Boot. It helps students register complaints and allows administrators to manage and update complaint statuses.

## Technologies Used
- Java 21
- Spring Boot
- Spring Security
- JWT Authentication
- Spring Data JPA
- H2 Database
- Maven

## Features
- User registration and login
- JWT-based authentication
- Role-based access control for students and administrators
- Submit and view complaints
- Update complaint status
- Exception handling

## How to Run
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java 21 is configured.
4. Run `CampuscomplaintApplication.java`.
5. Test the APIs using Postman.
